# 엑셀 파일 병합 도구 (Excel Merger Tool)

여러 개의 엑셀 파일을 하나로 병합하는 Windows용 도구입니다.

## 주요 기능

- 📁 **다중 파일 병합**: 1~100개의 엑셀 파일을 하나로 통합
- 🔍 **summary 시트 자동 인식**: 각 파일의 summary 시트 2행 데이터 추출
- ✅ **자동 검증**: 헤더 검증, 파일 형식 검증, 오류 처리
- 📊 **로그 기록**: 전체 처리 과정을 로그 파일로 저장
- 💾 **단독 실행**: 별도 설치 없이 .exe 파일만으로 실행

## 사용 방법 (.exe 실행 파일)

### 1. 프로그램 실행

`ExcelMerger.exe` 파일을 더블클릭하여 실행합니다.

### 2. 저장 위치 선택

결과 파일과 로그 파일이 저장될 폴더를 선택합니다.

### 3. 파일 선택 방법 선택

- **예**: 폴더 선택 (폴더 내 모든 .xlsx/.xls 파일 자동 인식)
- **아니오**: 파일 직접 선택 (Ctrl+클릭으로 다중 선택)

### 4. 병합 진행

선택한 파일들이 자동으로 병합됩니다.

### 5. 결과 확인

- **병합 파일**: `merged_summary_YYYYMMDD_HHMM.xlsx`
- **로그 파일**: `merger_log_YYYYMMDD_HHMM.txt`

## 요구사항

- **운영체제**: Windows 10 이상
- **파일 형식**: .xlsx, .xls
- **시트 구조**: 각 파일에 `summary` 시트 필요 (대소문자 구분 안 함)
- **데이터 위치**: summary 시트의 2행에 데이터 필요

## 주요 규칙

### 파일 검증

✅ **처리되는 파일**:
- .xlsx, .xls 확장자
- summary 시트 포함
- 2행에 데이터 존재

❌ **스킵되는 파일** (로그에 기록됨):
- 지원하지 않는 파일 형식
- summary 시트 없음
- 2행이 완전히 비어있음
- 파일이 잠겨있음 (다른 프로그램에서 사용 중)

### 헤더 검증

첫 번째 성공 파일의 1행이 헤더로 사용됩니다.

**오류가 발생하는 경우**:
- 1행이 완전히 비어있음
- 1행에 병합된 셀 포함
- 1행에 날짜 형식 포함
- 1행에 수식 포함

## 로그 파일 형식

```
[2025-12-13 10:30:15] [INFO] === 파일 병합 시작 ===
[2025-12-13 10:30:16] [SUCCESS] Report_A.xlsx - 15 columns extracted
[2025-12-13 10:30:17] [SKIP] Report_B.xlsx - summary 시트 2행 전체가 비어있습니다.
[2025-12-13 10:30:18] [ERROR] Report_C.xlsx - 파일이 잠겨있습니다.
[2025-12-13 10:30:19] [INFO] === 병합 성공 ===
[2025-12-13 10:30:19] [SUCCESS] 병합 완료: merged_summary_20251213_1030.xlsx
```

## 문제 해결

### Q: "파일이 잠겨있습니다" 오류가 발생합니다
**A**: 엑셀 파일이 다른 프로그램(Excel 등)에서 열려있습니다. 해당 파일을 닫고 다시 시도하세요.

### Q: "summary 시트가 없습니다" 오류가 발생합니다
**A**: 각 엑셀 파일에 `summary`라는 이름의 시트가 있는지 확인하세요. (대소문자 구분 안 함)

### Q: "2행 전체가 비어있습니다" 메시지가 나옵니다
**A**: summary 시트의 2행(A2부터)에 데이터가 있는지 확인하세요.

### Q: 최대 몇 개의 파일을 병합할 수 있나요?
**A**: 최대 100개까지 가능합니다.
